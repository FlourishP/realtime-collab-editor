# Realtime Collaborative Editor

Real-time collaborative code editor with multi-cursor support, syntax highlighting, and live chat.

## Features
- Multi-cursor real-time editing via Socket.io
- Syntax highlighting for 10+ languages
- Live chat sidebar for team communication
- Cursor presence indicators
- Auto-save with conflict resolution

## Tech Stack
Next.js 14, TypeScript, Socket.io, Monaco Editor, Tailwind CSS

## Getting Started
```bash
npm install
npm run dev
```
